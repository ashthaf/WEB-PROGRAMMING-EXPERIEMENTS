# 🌐 Web Programming Experiments

A collection of web development experiments and mini-projects created while learning and practicing web programming. This repository contains different websites and interactive applications built using HTML, CSS, and JavaScript.

## 📚 Projects Included

| Project | Description |
|---|---|
| CRUD | Basic Create, Read, Update, and Delete operations |
| Employee Management | Employee management interface |
| Interactive Image Gallery | Interactive gallery for displaying images |
| Multi-page Business | Multi-page business website |
| Responsive Home Page | Responsive website homepage |
| Client-Side Form Validation | Form validation using JavaScript |
| Contact Form | Contact form webpage |
| Live Search | Search interface with dynamic filtering |
| News Feed | News feed webpage |
| Portfolio | Personal portfolio website |
| Product Catalogue | Product listing with search/filter functionality |
| Product Landing Page | Product promotional website |
| To-Do List | Task management application |
| User Authentication | Login and registration interface |
| Weather Information | Weather information webpage |

## 🛠️ Technologies Used

- HTML5 – Website structure
- CSS3 – Styling, layouts, and responsive design
- JavaScript – Interactivity and client-side functionality

## 🎯 Learning Objectives

- Understand HTML structure and semantic elements
- Practice CSS styling and layouts
- Learn responsive web design
- Implement JavaScript functionality
- Work with forms and client-side validation
- Manipulate DOM elements
- Build interactive web applications
- Improve frontend development skills through practical projects

## 🚀 How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/ashthaf/WEB-PROGRAMMING-EXPERIEMENTS.git
   ```

2. Navigate to the repository:

   ```bash
   cd WEB-PROGRAMMING-EXPERIEMENTS
   ```

3. Open any project folder.

4. Open its `index.html` file in your browser.

   Alternatively, use **Live Server** in Visual Studio Code for a better development experience.
